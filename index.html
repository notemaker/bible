三步接上 Google Sheet

  1. 01
    建立工作表

    新增 `Media` 與 `Lists` 工作表，第一列貼上規格中的欄位名稱。

  2. 02
    貼上 Apps Script

    使用專案內 `apps-script/Code.gs`，在 Script Properties 設定 `SPREADSHEET_ID`。

  3. 03
    部署為 Web App

    執行身分選「自己」，存取權依你的使用情境設定，再把 `/exec` URL 貼回這裡。
